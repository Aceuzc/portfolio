Case Study

Panahon PH Weather Dashboard

A live weather dashboard built to make Philippine city conditions easier to search, compare, and scan across devices.

Open Live Demo View GitHub
Role Frontend developer
Stack HTML, CSS, JavaScript, REST API
Focus Search, weather data, responsive UI

Project Problem

Most beginner weather projects show one city at a time. I wanted this version to feel closer to a real utility: fast city lookup, visible current conditions, map context, and a watchlist for common Philippine cities.

What I Built

  • City search flow for Philippine locations.
  • Current condition cards for temperature, humidity, wind, pressure, and visibility.
  • Map-focused layout with a live location marker.
  • Watchlist view for quickly comparing major cities.

Technical Decisions

  • Kept the interface in vanilla JavaScript to prove DOM and API fundamentals.
  • Used compact weather cards so the dashboard stays scannable on smaller screens.
  • Designed dark surfaces around blue weather-map tones for a consistent product feel.
  • Separated proof points from stack tags so the project reads as outcome-led.

A Decision That Mattered

I chose a sidebar-based city watchlist over a dropdown because I wanted multiple cities visible at once without switching views. That one layout call forced me to rethink the whole grid — the map, the conditions panel, and the forecast cards all had to reflow around it. It ended up being the decision I learned the most from.

What This Shows

This project demonstrates API integration, interface hierarchy, responsive dashboard layout, and practical UX decisions. It gives visitors a clearer picture of how I think through a project, not only what the final screen looks like.
